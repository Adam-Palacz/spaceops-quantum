Encode/decode round-trips integer slack, including the optimum slack 1/0/0. A Qiskit string is reversed explicitly before decoding. No QUBO coefficients and no Qiskit import.

Evidence 2026-11-15 (local, uncommitted): `uv run ruff check .` → all checks passed; `uv run pytest -q` → 102 passed. `build_qubo` expands `-priority + sum λ (cost + slack - budget)^2`. A hand expansion gives constant 2, linear (-5, -2) and product coefficient 4. F0 with λ=41 has constant 12300 and 18 logical qubits; sampled vectors match the direct square. No Ising conversion and no Qiskit import.
